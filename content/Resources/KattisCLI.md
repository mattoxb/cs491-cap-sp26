---
title: Kattis CLI
---

Kattis has a [CLI Utility](https://github.com/Kattis/kattis-cli) that will enable you to submit your
code from the command line and see the result without needing to go to the web site.

You need to create a `.kattisrc` for this to work.  You can get that [here](https://illinois.kattis.com/downloads/kattisrc).  See the instructions in the Github repository for more information.
